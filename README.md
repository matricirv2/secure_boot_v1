# secure_boot_v1
## Description 
  - Secure boot implementations on Xilinx FPGAs, the exact method is still under development.

### Boot methods 
 - JTAG
 - SPI/QSPI flash boot
 - BPI (parallel) flash
 - Master/Slave SelectMAP
 - PCIe-based reconfiguration
### In the field methods 
 - Dual/fallback (golden) image
 - In-System Configuration (ISC)
 - Partial Reconfiguration (PR)
 - Secure/authenticated update flows
